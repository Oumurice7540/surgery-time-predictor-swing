# 人工資料操作驗收

全部為人工病例，240 筆，與真實病患無關。

1. 第一頁選擇本資料夾，點個別報表查看來源預覽。選來源不改變已套用資料。
2. 正式轉檔請只選 `病例原始.csv`，到第二頁按「執行驗證與轉檔」。CSV 對話框按「DRG／麻醉時間轉檔」。
3. 「合併 DRG 對照」選 `DRG對照.csv`、UTF-8；病例鍵 DRG碼、對照鍵 代碼，加入科別與權重。匹配 240 筆、未匹配 0 筆。
4. 「由麻醉起訖計算分鐘」選麻醉開始與麻醉結束，勾選跨午夜假設；計算 60～109 分鐘。未勾選會拒絕。按完成後重新確認欄位對應：預測目標 = 麻醉分鐘，年齡 = 年齡，術式 = 手術名稱，ID = 案例編號；檢查並套用。
5. 可先「匯出完整轉檔資料」，同時保存 .audit.txt。第二頁也能匯出完整已套用資料。畫面前 100 筆，匯出全部 240 筆。
6. 第四頁可加入年齡 MIN_MAX、DRG_科別 CATEGORY_CODES、檢驗值 Z_SCORE；預覽為探索估計，儲存／載入 .steps，套用。需要列篩選時放在 IQR 與數值轉換之前。
7. 第五頁選年齡、DRG_科別、檢驗值。先按訓練集評分。第六頁比例 80%、種子 123，切換模型輸入預覽：192 訓練、48 測試；IQR 若移除訓練列，處理後數量會不同，測試仍保留。
8. 第七頁單一或四方法訓練，第八頁檢查兩組指標及逐筆結果。保存模型，重新開啟後第九頁載入，輸入同一組條件，分鐘應一致。
9. 類別選單可以輸入新類別；新動態模型以 unknown／-1 編碼，字典不擴張。檢驗值空白使用訓練平均補值；常數欄轉換為 0。
10. 改用重複鍵對照檔應拒絕合併，病例不增加。未匹配示範檔保留 240 筆、匹配 120、未匹配 120，新增欄缺值。

也可直接匯入「已轉檔可直接匯入.csv」測試第 3～9 頁；該檔的科別欄名沒有 DRG_ 前綴。
