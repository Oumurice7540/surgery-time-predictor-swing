# 1.7.0：PPT 流程與功能補齊（2026-10-04）

維持 Java 21、Swing、Maven、WEKA。依實際 PPT 截圖與原始碼補齊功能，保留先前未提交修改。PPT 對照與已知差異見 `PPT_PARITY.md`，驗證步驟見 `TESTING.md`。

- 第一頁：選資料夾／多檔後停留本頁；點選個別 CSV 即讀取該檔前 100 筆，支援 UTF-8、Big5、UTF-16LE。來源預覽與已套用訓練資料分頁顯示，不會暗中換資料。
- 第二頁：欄位對應對話框新增「DRG／麻醉時間轉檔」。每份來源可指定 DRG 兩側鍵及加入欄位；重複／空白對照鍵拒絕，未匹配病例保留、列出鍵，不增加病例列。起訖時間支援 ISO 日期時間與時刻；無日期跨午夜必須明確勾選，缺值／同時刻歧義拒絕，秒數四捨五入至整數分鐘。來源不覆寫，完整結果與合併紀錄可匯出。
- 第三頁：保留六項統計，加折線圖；圖表列出主題、分鐘／人次、有效／全部母數。折線橫軸是群組順序，不冒稱時間趨勢。
- 第四頁：加入類別數值化、Min-Max、Z-score，可與原有步驟一起新增、修改、排序、移除、儲存、載入。探索預覽使用全部資料；正式訓練重新估計，不拿探索數值訓練。固定條件篩選先於 IQR，數值轉換最後。
- 第五頁：左側上下選取前／後資料；右側勾選、欄名、分數與方法。訓練前評分只用訓練分割：數值 Pearson r²、類別相關比 η²。此方法不是原軟體未提供公式的重要度，也不同於訓練後測試 permutation importance。合適輔助欄可主動勾入模型，ID／目標與明顯識別／時間欄排除。
- 第六、七頁：原始值與真正交給 WEKA 的數值欄位可切換，顯示擬合參數。第七頁只顯示所選演算法適用參數；保留單一／四方法訓練，不重新生成資料。
- 第八頁：同時顯示訓練／測試的 MAE、RMSE、R²、筆數與各自評估耗時，另列訓練評估總耗時。兩組完整逐筆預測可切換，模型與四方法比較仍可保存／使用。Permutation 無正增幅時呈現 0，不再捏造均分重要度。
- 第九頁：含新欄位的模型動態建立輸入元件，類別字典、數值缺值平均及尺度參數隨模型保存；未知類別使用固定 unknown／-1，不重估。結果視窗列出本次全部輸入與分鐘，內容可捲動。

## 轉換與拆分約定

1. 固定條件篩選／刪欄先套用到待訓練資料；以比例與種子拆分。
2. IQR 正式界線只使用訓練集估計，僅剔除訓練列，測試列不因目標或輸入極端而刪除。界線與筆數保存於模型資料版本／前處理資訊。第四頁 IQR 前後是探索結果；套用 CSV 保存待拆分原始值，因此探索筆數與正式訓練筆數可能不同。
3. 類別字典、缺值平均、Min-Max、Z-score 只由保留的訓練列估計。標準差使用母體定義；常數欄除數取 1，訓練值轉為 0。測試／新資料 Min-Max 可以超出 0～1，不裁切。
4. 類別數值化依訓練類別排序編成 0 起始整數，未知及空白為 -1；未指定數值化的動態類別採 one-hot，分開 missing／unknown。全缺值的訓練欄無法估計，會拒絕訓練。
5. 保留既有十欄、未新增轉換的模型路徑與舊模型編碼；其未知類別規則仍為舊版規則。新增轉換或新欄位才採新的保存管線。
6. 保留 WEKA 自身的內部訓練正規化；第六頁顯示的是交給分類器的 Instances，不宣稱可觀察分類器所有內部狀態。常數目標的 R² 採本程式既有約定 0。
7. 最高仍為 100,000 病例；動態 one-hot 每欄最多 5,000 維、總 20,000 維，訓練矩陣最多一千萬格，超出會明確提示縮減欄位。

# 手術時間智慧系統（Java 21 Swing＋WEKA 多演算法）

本專案依參考簡報的功能流程與視覺方向製作，包含九個可自由切換的頁面：

1. 資料來源：選擇含月報表的資料夾、一份或多份 CSV，或使用系統虛擬病例。
2. 資料轉檔：驗證、合併並建立統一格式 CSV，可直接開啟檢視。
3. 資料統計：依手術、手術室、醫師、ASA 等欄位計算筆數與時間圖表。
4. 資料處理：依欄位篩選、刪列、刪欄與 IQR 處理，儲存／載入步驟並輸出處理後 CSV。
5. 特徵選取：決定真正送入 one-hot 編碼與所選 WEKA 模型的欄位。
6. 資料拆分：設定訓練／測試比例與可重現亂數種子。
7. 方法設定：選擇 BPNN／RandomForest／LinearRegression／SVR，設定適用參數與預測區間目標後執行訓練。
8. 訓練結果：顯示測試集 MAE、RMSE、R²、欄位重要度與逐筆對照，並可儲存模型。
9. 手術時間預測：將病例條件送入使用中的 WEKA 模型，也可切換至另一個已儲存模型。

## 重要限制

程式會真正執行機器學習訓練與預測，內建範例為人工生成的虛擬資料，也可由使用者匯入自己的 CSV。是否為真實資料取決於匯入來源；本程式沒有經過臨床驗證，不可用於醫療決策。

## 技術規格

- 程式語言：Java 21
- 圖形介面：Swing（不含 JavaFX）
- 檔案選擇：AWT `FileDialog`，在 Windows 顯示原生檔案總管介面
- 專案管理：Maven Wrapper
- 版本控制：Git 與 GitHub Actions
- 資料格式：UTF-8 CSV
- 機器學習套件：WEKA 3.8.7
- 模型：WEKA `MultilayerPerceptron`、`RandomForest`、`LinearRegression`、`SMOreg`（RBF SVR）
- Python：完全不使用

## 程式執行流程

1. 在資料來源頁選擇月報表 CSV 或虛擬病例。
2. 資料轉檔頁讓使用者對應每份 CSV 的欄位；逐列檢查通過後才合併成單一標準 CSV。
3. 使用者先檢視分組統計，再設定篩選、刪除及 IQR 處理步驟。
4. 使用者選取輸入特徵，並設定訓練／測試比例及亂數種子。
5. 到方法設定頁選擇演算法與適用參數；只有按下「執行模型訓練」才會開始訓練。
6. 程式以指定種子打亂資料，再切成訓練集與測試集。
7. 只用訓練集建立已選特徵的類別字典與數值／one-hot 編碼；測試集未見類別使用該群組全零向量。
8. 建立所選 WEKA 迴歸模型，套用對應參數並呼叫 `buildClassifier()`。BPNN 與 SVR 的正規化由模型使用訓練資料估計。
9. 使用未參與權重學習的測試集計算 MAE、RMSE、R²、permutation importance 與殘差預測區間。

### BPNN 超參數允許與建議範圍

| 超參數 | 程式允許範圍 | 建議範圍 | 數值影響 |
| --- | --- | --- | --- |
| 隱藏層神經元 | 1–128 | 8–64 | 越多可學較複雜關係，但較慢且可能過度擬合 |
| Epoch | 50–2,000 | 300–1,000 | 太少可能學不完；太多會增加訓練時間 |
| Alpha（Momentum） | 0–0.90 | 0.10–0.80 | 保留上次更新方向；太高可能震盪 |
| Eta（Learning rate） | 0.001–1.0 | 0.05–0.30 | 太大可能不穩定；太小會學得很慢 |
| 預測區間目標 | 80%–99% | 90%–95% | 目標越高，預測區間通常越寬 |

BPNN 預設值為隱藏層 16、500 Epoch、Alpha 0.2、Eta 0.1、區間目標 90%。先前版本曾以相同的 10,000 筆虛擬 CSV 與 70% 訓練比例比較，這組設定得到 MAE 11.73 分鐘、RMSE 15.51 分鐘、R² 0.823，且訓練約 16.9 秒；原簡報的 60、1,000、0.8、0.2 在同一份資料得到 MAE 20.3 分鐘、RMSE 25.8 分鐘、R² 0.511，訓練約 145.7 秒。這只是本份虛擬資料的可重現比較，不保證適合其他匯入資料；每項仍可調整並真正影響訓練。

### 虛擬資料欄位

```text
case_id,operating_room,age,sex,procedure,surgeon_code,urgency,asa_class,anesthesia,comorbidity_count,complexity,actual_minutes
```

- `case_id`：依序產生的虛擬案例編號。
- `operating_room`：手術室代碼。
- `age`：虛擬年齡。
- `sex`：會進入 one-hot 編碼；生成公式刻意不設定性別效果。
- `procedure`：手術名稱，是主要時間基準來源。
- `surgeon_code`：`S001` 到 `S004` 的虛擬醫師代碼，不是人名。
- `urgency`：常規或緊急手術。
- `asa_class`：`ASA I` 到 `ASA IV` 的虛擬術前身體狀況分級。
- `anesthesia`：全身、區域或鎮靜麻醉。
- `comorbidity_count`：虛擬共病數，允許 0–4。
- `complexity`：標準、複雜或高複雜。
- `actual_minutes`：虛擬基準與隨機誤差合成的教學標籤。

### 匯入自己的病例 CSV

1. 在「資料來源」選擇 CSV 或資料夾，再到「資料轉檔」按「執行驗證與轉檔」。
2. 在「CSV 欄位對應與匯入檢查」確認編碼（UTF-8、Big5 或 UTF-16LE）。若字元不正確，改編碼後按「讀取／重新讀取欄位」。一批檔案使用相同編碼。
3. 每份檔案有自己的分頁。把來源欄名對應到年齡、手術名稱、主治醫師等欄位；不必預先改欄名。同名欄位以欄位編號區分。
4. 選擇「預測目標時間」欄位，並確認目標名稱（手術時間、麻醉時間或自訂名稱）。這是持續時間，不能直接選手術開始時刻。不同檔案的目標欄必須表示同一件事。
5. 指定時間格式：分鐘、時:分，或自動。`03:35` 轉成 215 分鐘；25:30 為 1,530 分鐘；小數分鐘四捨五入為整分鐘。尚不支援起訖時間相減或 Excel 日期序號。
6. 按「檢查所有資料」。報告列出檔案、實際起始列號、欄位、錯誤原因，可匯出完整 CSV。資料有錯時整批不套用，不會默默略過問題列。修正檔案內容後可重新檢查；欄名變動則重新讀取欄位。
7. 檢查通過後按「套用已通過的資料」，再繼續統計、特徵選取與訓練。原始檔不會被覆寫，標準資料另存為 `generated-data/imported-*.csv`。

匯入至少需要一項輸入特徵和一個目標時間欄，資料量為 200–100,000 筆。十項輸入特徵可選用；未對應的欄位不會進入訓練。年齡接受 0–120 的整數、共病數接受 0–1,000 的整數。手術名稱、醫師、性別、手術室、ASA 與其他文字類別直接從資料讀取，不再限於內建選項。

案例編號可不對應，程式以來源檔序號及資料起始列號建立本次匯入的唯一 ID；若有對應，必須非空且整批唯一。不要把會重複的病歷號直接當作單次手術的案例編號。所有已對應欄位的空值均會列為問題，沒有自動補值。多檔合併可使用不同欄名與順序，但必須對應相同的輸入特徵。

預測頁只顯示目前模型使用的欄位，選項及預測目標跟著模型存檔與載入。準備新的 CSV 不會改變仍在使用中的舊模型。標準 CSV 使用 `actual_minutes` 保存目標分鐘；重新匯入標準 CSV 時仍須確認目標名稱及要使用的特徵。

目前處理的是 CSV，沒有直接讀取 `.xlsx` 或 `.xls`。可先從 Excel 另存 CSV。支援引號中的逗號、雙引號及跨行內容。十種特徵以外的新欄位（例如醫師年資）尚未加入模型。

## BPNN 是什麼

BPNN 是 Backpropagation Neural Network，中文常稱「反向傳播類神經網路」。資料先進入輸入層，經過一個隱藏層，最後輸出預測分鐘。訓練時先算誤差，再從輸出端往回修正每條連線的權重。Eta 控制每次修正的步幅，Alpha 保留一部分上次更新方向。

## 如何解讀畫面數值

- MAE：平均每筆預測相差幾分鐘，越小越好。
- RMSE：大誤差會被加重的平均誤差，越小越好。
- 正規化 MAE／RMSE：分鐘誤差除以「測試集最大實際分鐘－最小實際分鐘」，方便比較不同時間尺度；畫面會同時保留容易解釋的分鐘值。
- R²：模型解釋測試資料變異的程度，越接近 1 越好。
- 特徵重要度：逐欄打亂測試資料，觀察 RMSE 增幅並換成百分比。這是模型依賴程度，不是醫療因果關係。
- 殘差區間：依使用者指定的百分位，使用測試集絕對誤差建立上下寬度，不是個別病人的信心度。
- 訓練前後 RMSE：WEKA 未公開逐 Epoch 回呼，因此畫面只顯示 Epoch 0 基準與最終結果，不捏造中間曲線。

WEKA 官方資料：[MultilayerPerceptron API](https://weka.sourceforge.io/doc.stable/weka/classifiers/functions/MultilayerPerceptron.html)、[Maven 使用說明](https://waikato.github.io/weka-wiki/maven/)。

## 儲存與載入模型

在「訓練結果」頁面按下「儲存模型」，可輸出 `.model` 檔。預設檔名會自動加入儲存日期與時間，例如 `WEKA_RANDOM_FOREST_20260929_193000.model`，也可以自行改名。檔案第一部分是所選演算法真正訓練出的 WEKA classifier，並一併保存 WEKA 欄位結構、one-hot 編碼字典、預測區間校準結果、訓練超參數及完整訓練結果。若選到既有檔案，程式會先詢問是否覆蓋。

在「手術時間預測」頁面的「使用中模型」卡片按下「載入模型」，即可選取另一個 `.model`。載入後，神經網路、欄位編碼、超參數、預測區間與訓練結果頁會一起切換；不屬於本程式支援的四種模型、演算法與設定不一致，或內容不完整的檔案會被拒絕，原本模型仍會保留。Java 模型檔屬於序列化資料，請只載入由本程式建立且來源可信的檔案。

## 第二階段：資料處理流程（1.2.0）

1. 匯入 CSV 並完成欄位對應。未對應的來源欄（例如「科別」）保留為輔助欄，可以篩選，但不自動加入模型。
2. 到「資料處理」選擇操作、欄位和值，按「新增步驟」。可以更新、移除、上移或下移步驟。
3. 按「預覽全部步驟」，在下方分頁檢查原始資料、結果及每一步的筆數與 IQR 範圍。
4. 按「套用結果並繼續」，另存完整的 processed-*.csv 與同名 .steps，再進入特徵選取及訓練。
5. 按「儲存步驟」可重用流程；匯入另一份相同欄位、相同目標的資料後「載入步驟」，重新預覽、套用。

支援文字等於／包含的保留與刪除、數值範圍保留與刪除、刪除空白列、刪除欄位及指定數值欄 IQR。文字先去除頭尾空白並區分大小寫；數值範圍包含上下界。IQR 使用 nearest-rank 四分位數，預設 1.5 倍；空白值保留且不參與計算，非數值會報錯。輔助欄若與標準 CSV 欄名衝突，輸出會加「來源_」避免同名。

每次預覽都從本次匯入／生成的原始快照重算。預覽、載入步驟及清空草稿都不會立即改變待訓練資料；清空後預覽、套用才會還原原始資料。結果不足 200 筆不能套用；案例編號、目標欄與最後一項模型特徵不能刪除。刪掉模型特徵後，特徵選取、CSV 輸出和後續訓練都排除此欄，已訓練的模型則保留到下一次成功訓練。

處理發生在訓練／驗證資料拆分之前，因此評估結果代表篩選後的資料族群。步驟使用本程式的 UTF-8 `.steps` 格式，不保證能讀取參考簡報原軟體的步驟檔。步驟檔保存規則，不包含原始資料或模型。

快速展示：匯入 `examples/科別資料處理範例.csv`（800 筆合成資料），在資料處理載入 `examples/科別資料處理範例.steps`。結果應為「800 → 耳鼻喉科 400 → 移除時間離群值 399」，再刪除性別欄；保留年齡及手術名稱兩項模型特徵。


## 第三階段：多演算法訓練（1.3.0）

「方法設定」最上方新增演算法選單。切換方法只改變下次訓練設定；完成訓練之前，原本的模型繼續使用。畫面僅啟用適用參數，儲存／載入模型會連同方法、參數、編碼字典、目標與完整評估結果一併保存。

| 演算法 | 可調參數 | 預設 |
| --- | --- | --- |
| BPNN | 隱藏層、Epoch、Alpha、Eta | 16、500、0.2、0.1 |
| RandomForest | 樹數、最大深度（0 不限制） | 100、0 |
| LinearRegression | Ridge 正則化 | 0.00000001 |
| SVR（SMOreg + RBF） | C、Gamma | 1、0.01 |

RandomForest 的樹數允許 1–1000、深度 0–100；Ridge 允許 0–100；C 允許 0.001–10000；Gamma 允許 0.000001–100。線性迴歸不做自動特徵選擇；共線欄位仍由 WEKA 內部處理。

各方法沿用相同資料、特徵、拆分比例與種子。固定這些設定後可逐次訓練不同方法、查看 MAE／RMSE／R² 與完整測試集對照，並分別儲存模型。1.4.0 已加入同條件比較表與一鍵訓練四種方法；沒有自動搜尋參數或自動挑選最佳模型。

非 BPNN 圖表使用「0 基準／1 完成」作為橫軸，不把一次模型擬合稱作 Epoch。BPNN 仍只顯示訓練前與完成後兩點，不宣稱取得逐輪曲線。預測分鐘下限設為 1，評估與預測使用相同下限；指標保留未取整的預測精度，表單結果顯示整數分鐘。

1.0／1.1／1.2 的 BPNN `.model` 可繼續載入。新版本的其他演算法模型需使用 1.3.0 或更新版本。模型檔是 Java 序列化檔案，仍只應載入可信來源。

快速驗收：沿用「科別資料處理範例.csv／.steps」得到 399 筆資料後，在方法設定依序選擇不同演算法訓練；資料筆數應維持 399，特徵應為年齡與手術名稱。測試所得數值代表這份合成資料，並非醫院資料表現。


## 訓練歷史與四種模型比較（1.4.0）

1. 完成資料準備後，在「方法設定」按「以目前設定訓練四種方法」，依序執行 BPNN、RandomForest、LinearRegression、SVR。各方法使用目前保留的對應參數值（包含其他方法停用的欄位），以及相同資料、特徵、目標、比例與種子。可先切換演算法調整參數，再執行全部。
2. 在「訓練結果」頂端比較表同時檢視每次成功結果。單獨訓練也會追加紀錄，不覆蓋前一次。
3. 點 MAE／RMSE／R² 欄名排序；選取一列後按「使用選取模型」，下方完整結果及預測頁同步切換。待訓練資料不因此改變。
4. 「匯出目前比較表」輸出目前篩選及排序後的全部紀錄；「匯出選取預測明細」輸出該次完整測試集，保留數值精度；「儲存選取模型」可直接保存任何歷史模型，不必先切換。

比較組以模型資料內容及順序、所選特徵、預測目標、拆分比例及種子的 SHA-256 識別。預設只顯示與使用中模型同條件的紀錄，取消勾選可查看其他組；不同組不能直接作為公平效能排名。匯出的 CSV 帶完整比較組識別與訓練參數。更換演算法／超參數不會改變比較組。

歷史與模型保留在本次程式記憶體中，關閉後不自動還原；關閉前請匯出比較表、預測明細及需要的 `.model`。外部載入模型沒有可驗證的本次來源指紋，因此不加入同條件比較紀錄。一鍵訓練中途若失敗，已完成的紀錄保留；不會將未完成方法標為成功。

這次僅新增比較與匯出。既有預測區間校準、拆分前 IQR 與特徵重要度計算方式未修改；比較功能不代表先前指出的評估方法問題已修正。
